# Overview

This project was designed to be a growing opportunity where I could learn how to program with rust. It gave me experience with the language and taught me important principles regariding ownership / borrowing, stacks / heaps, variable declarations, basic rust syntax, and more.

This software is a PDF writer. It collects a series of inputs from the user and creates a downloadable PDF based on the user input. In this case, the PDF is a letter writer. It collects user name + address as well as recipient name + address. You then are able to type the body of the letter and upon completing the letter, it opens the document in a new tab. 

The purpose was to gain experience with rust, but also to create a framework for knowing how PDF documents can be designed in programing. Now I am able to create additional PDFs in the future based on my experience with this project.
